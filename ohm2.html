질문 2 전구를 병렬로 추가할 때 기존 전구와 추가된 전구의 밝기는 어떻게 변화할까요?

정답: 처음과 똑같이 밝다

💡 까닭: 병렬 연결에서는 각 저항(전구)에 걸리는 전압이 같아 전구를 추가하더라도 각 전구에 흐르는 전류의 세기가 변하지 않기 때문입니다.

질문 3 전구 1개의 필라멘트를 끊었을 때(✂️) 직렬연결과 병렬연결은 각각 어떻게 될까요?

정답: 직렬은 모두 꺼지고, 병렬은 나머지가 계속 켜져 있음

💡 까닭: 직렬은 전류가 흐르는 회로가 하나뿐이어서 연결이 끊기면 전체 전류가 차단되지만, 병렬은 다른 갈래의 우회도로(회로)가 남아있어 계속 전류가 흐를 수 있습니다.

📊 직렬연결과 병렬연결의 특징 비교

직렬연결 특성

  • 전체 저항: 연결할수록 전체 저항이
    $$R_{전체} = R_1 + R_2$$
  • 전류의 세기: 회로 전체에 흐르는 전류는 저항을 추가할수록
  • 연결 끊김: 하나가 끊어지면 길이 하나뿐이라
  • 생활 속 이용: 퓨즈, 장식용 꼬마전구(일부), 화재 감지기
직렬 연결

병렬연결 특성

  • 전체 저항: 연결할수록 전체 저항이
    $$\frac{1}{R_{전체}} = \frac{1}{R_1} + \frac{1}{R_2}$$
  • 전압과 밝기: 각 저항에 걸리는 전압이 같아 전구의 밝기가
  • 연결 끊김: 하나가 끊어져도 다른 길이 있어
  • 생활 속 이용: 가정용 전기 배선, 멀티탭, 가로등, 자동차 전조등
병렬 연결
